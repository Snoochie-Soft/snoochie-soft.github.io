# snoochie-soft.github.io

Static site of the **Snoochie Soft** studio, served by GitHub Pages (`.nojekyll` disables Jekyll).
The home page and the six app pages are generated by a small Node script with no dependencies;
the legal pages are hand-written HTML and are never touched by the generator.

## Build

```
node tools/build.mjs      # writes the home page, app pages, 404.html and sitemap.xml
node tools/og.mjs         # renders the 1200x630 OG cards into img/og/ (headless Chrome)
```

Commit the generated HTML: GitHub Pages serves the files as they are.

| Path | Purpose |
|---|---|
| `content/catalogue.json` | facts: apps, SNS numbers, Play URLs, screens, legal links, colours, languages |
| `content/en.json` | every visible English string |
| `content/TRANSLATING.md` | how to add a language, length caps, glossary |
| `tools/build.mjs` | generator (`--content`, `--out`, `--langs` for dry runs) |
| `tools/build-langs.mjs` | `LANGS_BUILT`: the languages that are built and shown |
| `tools/templates.mjs` | HTML templates (no copy inside) |
| `tools/check-lang.mjs` | checks a translation against `en.json` |
| `tools/og.mjs`, `tools/make-images.mjs` | OG cards and screenshot resizing (headless Chrome) |
| `css/label.css`, `js/label.js` | shared style and behaviour |
| `fonts/` | Unbounded, Schibsted Grotesk, Martian Mono (self-hosted, OFL licences next to them) |
| `ASSETS.md` | where every shipped image comes from |

## Pages

| URL | Source |
|---|---|
| `/` | generated: studio home (crate, desk, catalogue, house rules, contact) |
| `/szybciej-sie-nie-da/`, `/mossy/`, `/fakechat/`, `/loopclass/`, `/audio-transcriber/`, `/christian-pray/` | generated app pages |
| `*/privacy/`, `*/terms/`, `audio-transcriber/support/`, `audio-transcriber/licenses/` | hand-written legal pages, do not regenerate |
| `audio-transcriber/{pl,de,fr,es,pt-br}/` | older translated Transcriber pages, hand-written |
| `404.html` | generated |

Do not delete or change: `app-ads.txt` (AdMob), `google7bf347b91b7e4bc3.html` (Google
verification), `robots.txt`, `.nojekyll`. `audio-transcriber/sitemap.xml` is maintained by hand.

## Languages

English is at the site root. Other languages (PL, DE, ES, JA, PT-BR, FR, KO, ID; never Russian)
go to `/<lang>/` once `content/<lang>.json` exists and the code is added to `LANGS_BUILT`.
The language switcher stays hidden while only one language is built.

Before publishing Stage 1, read `_stage2/README.md` (kept out of git): the old Polish home and
Szybciej pages are indexed and must not be replaced by English without the `/pl/` build.

## Local preview

```
py -m http.server 8000
```

Open http://localhost:8000/. Light and dark themes follow the system setting.
